# Reveler-rs v0.2.0

A compact Swiss-style native editor with a clear hierarchy and fewer distractions.

- Put Target Level first, alongside True Peak and Max Gain, with live input/output meters and detector, gain, and limiter readings.
- Group the remaining parameters under More Controls; keep range labels on the three main sliders only.
- Add an accent-colored processing toggle that turns grey in bypass, with all processing controls dimmed.
- Add an integrated scrolling manual explaining the plugin, each control, and the meters.
- Open and close the manual with a reversible page-flip animation that keeps the plugin window size fixed.
- Preserve typed values, fine dragging, slider resets, and host automation gestures.
- Add native editor rendering and interaction tests, plus updated macOS editor lifecycle checks.

Audio processing, latency, parameter IDs, plugin IDs, and existing presets remain compatible. Available as VST3 and CLAP on Windows, Linux, and macOS, plus AUv2 on macOS. macOS bundles are ad-hoc signed without Apple notarization.
