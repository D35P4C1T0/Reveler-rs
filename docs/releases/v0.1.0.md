Initial release of Reveler-rs, a Rust audio leveler with adaptive gain and true-peak limiting.

- Per-channel adaptive envelopes and frequency-weighted loudness detection.
- Four-phase FIR peak detection and lookahead limiting.
- Mono, stereo, and 5.1 processing with independent LFE gain and limiting.
- Nine audio controls, latency-compensated bypass, and an egui/wgpu editor.
- Windows/Linux x86-64 VST3 and CLAP.
- Universal macOS VST3, CLAP, and self-contained stereo AUv2.

Extract the platform ZIP and copy the plugin into your DAW's plugin directory. macOS builds are ad-hoc signed without Apple notarization. Archives include dependency notices; `SHA256SUMS.txt` contains download checksums.
