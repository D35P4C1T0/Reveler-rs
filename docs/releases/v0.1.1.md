# Reveler-rs v0.1.1

- Fix macOS editor initialization crashes in REAPER for VST3 and AUv2.
- Use native Metal backing layers to avoid helper-class collisions when
  multiple plugin binaries are loaded in one host.
- Add macOS editor lifecycle and early-callback regression checks to CI.
- Document installation and macOS quarantine prompts.

DSP behavior and plugin identifiers are unchanged. macOS bundles remain
ad-hoc signed without Apple notarization.
